# ReClaude 网络线路

ReClaude 的客户端可使用 `config gateway test` 比较内置网关，也可用 `config gateway current` 查看当前选择。选定线路时使用客户端自带的 `config gateway set`；使用 `config gateway reset` 可恢复自动选择。命令的组织参数及具体用法以客户端帮助为准。

线路探测耗时只反映小请求延迟，不代表长上下文上传速度。排查时应结合正常任务的传输速率、TCP 重传和返回时间，避免重放模型请求。切换前确认是否影响正在运行的请求；不要为排障修改凭据、关闭 TLS 校验或频繁切换账号。

线路选择保存在本机绑定配置，不应提交账户配置、设备信息、密钥或运行数据到仓库。
