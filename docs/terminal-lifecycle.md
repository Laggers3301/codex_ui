# 侧边栏终端生命周期

- 每个终端绑定创建它的 WebSocket。关闭终端、连接断开、用户访问权失效、写入／缩放失败或执行请求超时后，先向原运行时终止进程，再释放归属。清理失败的记录保留，心跳继续尝试；未知进程编号不会被路由到其他 GPT 账号。
- 终端命令在独立回收程序保护下执行。Linux `/proc` 的进程启动时间和随机环境标记限定清理范围；后台进程、`setsid` 子进程以及忽略 HUP/TERM 的进程也会回收。其他终端的进程不在清理范围内。
- 此终端的 PATH 内提供 SSH 适配器，普通 `ssh host` 和 `ssh host command` 会为远端命令加入同样的回收程序。断开 SSH 后也清理远端子进程，防止残留的 `codex resume` 继续占用会话。远端须为提供 `/proc` 和 `/usr/bin/python3` 的 Linux 主机。原 OpenSSH 仍负责认证、主机校验和跳板；转发、子系统及配置／控制查询直接透传。
- 适配器只存在于该终端的临时目录，不修改系统 SSH 或用户配置。显式调用 `/usr/bin/ssh`、覆盖 PATH 或连接已经独立存在的 tmux/screen 会话不受远端回收保护；这些脱离终端的任务仍需用户自行管理。

验证包括真实 WebSocket 的主动关闭、断连、归属丢失、执行失败，以及临时 SSH 服务中的远端脱离进程组子进程。测试仅使用临时工作目录、临时密钥和本机测试端口。
