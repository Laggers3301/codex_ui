# 远程目录

完成连接、目录登记和网页可见性检查，让用户能在右侧“远程文件”栏展开目录、点击文件插入当前对话输入框。仅执行 SSH 命令或创建空文件夹不算完成。

## 连接信息和工作区

从本次请求、现有会话上下文和已登记目录获取目标主机、远程完整路径及用户的个人工作区。优先复用现有 SSH 别名或用户已经授权的连接；支持 `user@host`、自定义端口和密钥配置。只询问仍缺失且影响连接的信息。

网页以已登录用户的个人工作区为目录记录根。已登录的 `GET /api/remote-folders?threadId=<对话ID>` 返回 `workspacePath` 和此对话可用的目录；也可使用会话提供的个人工作区和已有目录记录。不要用服务器的系统登录名推断网页用户名，也不要把当前远程项目的子目录误当作个人工作区。

用户的主机、路径和简称存放在 `<个人工作区>/.codex/remote-folders.json`，不写入公用技能。该文件由下面的登记脚本维护。允许多个主机和目录，同名目录可用不同显示名称区分。

新登记绑定当前网页用户、当前对话。脚本优先读取 `CODEX_THREAD_ID`，其次读取 `CODEX_SESSION_ID`；环境缺失时，用本次会话明确提供的标识传入 `--thread-id`，不要从其他对话日志猜测。每个对话自行选择目录，不从其他对话、其他账号、示例路径或全局 SSH 配置添加默认目录。

区分“默认连接”和“默认目录”：用户添加默认连接时，只在该网页账号的各对话中提供这台电脑的连接选项，具体目录仍需各对话选择。不得用 `register --shared` 代替添加默认连接；它只用于用户明确要求所有对话共享某个目录的情况。打开网页或切换对话只读取当前账号的配置和已有挂载，不自动发起新的 SSH 连接。

当前账号已有远程连接时，新对话在右侧打开目录选择器，初始不选中目录；旧对话恢复自身已保存的目录。已配置电脑从当前账号的目录记录中读取，不扫描其他账号的 SSH 配置。用户点击“浏览电脑盘符/目录”时，通过该电脑的 SSH/SFTP 连接读取实际可访问的 Windows 盘符或 Linux/macOS 的根目录和主目录，不硬编码盘符；进入文件夹后点击“打开此目录”。新对话发送第一条消息前的选择暂存在独立草稿范围，创建对话后自动绑定真实对话 ID。文件栏的目录关闭按钮只关闭当前对话中的目录，关闭状态也应保存；关闭后可重新选择。

网页选择器依赖服务端 `remote-folder-control.py`、OpenSSH 和 SSHFS；SFTP 客户端依赖可按网页项目的 `remote-folder-requirements.txt` 安装到项目 `.remote-folder-deps`。它继承已有 SSH 别名、端口和密钥配置，通过参数数组调用，不执行远端脚本。没有可用网页选择器时继续使用下面的连接和登记流程。

## 连接目录

- 已有可用远程挂载时直接复用，保留用户指定的访问模式。可用 `list --all-conversations` 查找当前账号已有挂载；同一个目录再次登记会增加当前对话绑定，保留其他对话的绑定。
- SSH/SFTP 连接：先确认指定目录存在并能读取。按远端系统处理路径，Linux/macOS 保留绝对路径；Windows 先通过 SFTP 确认其盘符路径格式，不能一律假设 `/D:/`。需要 PowerShell 时使用 `-LiteralPath`，含特殊字符的脚本可用 UTF-16LE `-EncodedCommand`。
- 需要挂载时，在个人工作区内选择独立挂载点，建议 `远程目录/<名称>`；不同主机或路径的同名目录必须使用不同挂载点。使用 SSHFS 客户端及现有 SSH 配置；所需客户端放入用户目录，不改其他用户配置。挂载点应为空且不是符号链接。
- 浏览和引用默认只读；用户已请求编辑时可在该授权范围内使用可写挂载，并说明修改会直接写回远程文件。用参数数组调用工具，避免主机、路径和文件名成为 shell 代码。
- 复用 SSH 的密钥和主机校验。设置合理连接超时与存活检测；连接失败时按错误处理，没有新线索不要反复重试。不要自动开启重启后启动或无限重连。

SSHFS 调用示意，尖括号表示实际参数而非文字：

```text
<sshfs> <SSH目标>:<已验证的SFTP目录> <挂载点> -o ro,BatchMode=yes,StrictHostKeyChecking=yes,ConnectTimeout=10,ServerAliveInterval=15,ServerAliveCountMax=2
```

有些命令执行器会在命令结束时清理其子进程。必须在另一次工具调用中检查挂载仍然存在。若普通后台进程被清理且用户级 systemd 可用，可用唯一名称的临时用户服务运行 `sshfs -f`，设置 `Restart=no`，无需修改系统服务或设置开机启动。否则选择当前环境支持的进程保留机制。

在 Linux 挂载表中核对挂载点、来源和访问模式，做一次有超时的浅层目录读取。当前网页的目录读取服务使用 Linux 挂载表；FUSE/挂载不可用时如实说明限制，不把下载副本或空目录登记为实时远程目录。

## 登记到右侧文件栏

挂载验证成功后运行本技能的 `scripts/registry.py`：

```text
python3 <技能目录>/scripts/registry.py --workspace <个人工作区> register --name <显示名称> --host <主机或连接名称> --remote-path <远程路径> --mount-path <挂载点>
```

脚本读取挂载表得到实际只读状态，合并现有记录并原子写入。`thread_ids` 数组保存关联的对话；缺少此字段或值为 `null` 的旧记录只保留在最近使用列表，不能自动分配给对话。只有用户明确共享后带有 `shared: true` 的目录才允许跨对话显示。`remote-folder-views.json` 保存各对话明确选中或关闭后的目录 ID 列表，优先于目录绑定；空列表表示已关闭全部目录，不能恢复成其他对话的目录。脚本会同步这两份记录。不要直接修改网页共享数据库或读取登录凭证。

网页按服务端验证的登录用户和当前对话读取登记记录；客户端账号与登录账号不一致时拒绝读取，不能信任任意传入的用户名。切换账号或对话时清除旧目录树并丢弃旧请求的响应。右侧“远程文件”栏也有刷新按钮。连接成功后应看到根目录及第一层文件，展开子目录按需读取。文件点击后将路径插入现有输入框，不自动发送；目录旁的引用按钮可插入整个目录路径。此流程独立于左侧的项目列表，不要求用户另建项目。对话绑定用于组织文件栏，不改变底层挂载的操作系统访问权限。

具备已登录网页工具时验证文件栏和引用结果；只有命令工具时验证登记记录及读取服务结果，清楚区分已检查的部分，并让用户刷新网页查看。若网页尚未部署该文件栏，说明缺少前端支持，不能声称仅安装技能就会新增界面。

## 断开或移除

- 查看当前对话登记：`registry.py --workspace <个人工作区> list`；查看账号所有登记加 `--all-conversations`。
- 用户要求从当前对话文件栏移除时，可点击目录旁的关闭按钮，或运行 `registry.py --workspace <个人工作区> remove --id <目录ID>`。保留其他对话绑定和最近使用记录，方便重新打开；只有用户要求从所有对话移除登记时才加 `--all-conversations`。关闭或移除不删除文件，也不自动卸载。
- 用户要求断开时先检查该挂载是否还被其他对话使用；只移除当前对话目录不需要卸载。明确断开整个连接时才卸载准确挂载点，并核对对应临时用户服务。记录可保留供下次连接。
- 不对挂载点递归删除。远程掉线应显示读取错误，不能继续把挂载点下的空本地目录当成远程内容。
